# DeePlayer

**A full-featured desktop music player built in Python. Team project.**

![DeePlayer](screenshot/1.PNG)

## Features

- Play, pause, stop, next and previous
- Shuffle, repeat all and repeat one
- Volume control and mute
- Open a single file or a whole folder, then pick any track from the playlist
- Progress bar with elapsed and total duration
- Album art and a transparent window option

## Stack

Python, Tkinter, Pygame, Mutagen

## Run locally

```bash
pip install pygame mutagen
python main.py
```
